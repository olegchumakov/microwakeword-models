# microwakeword-models

Коллекция готовых моделей распознавания (wake word) для ESPHome / microWakeWord. Модели вшиваются в прошивку ESP32 при сборке.

Каждая модель — пара файлов в своей папке:

- `<имя>.json` — манифест (параметры детекции, ссылка на tflite)
- `<имя>.tflite` — модель (microWakeWord v2 «micro», int8, streaming)

## На базе чего обучались модели

Обучение — на синтетических данных (+ небольшой fine-tune на реальных записях, см. ниже): конфиг с целевыми фразами → синтез речи → мел-спектрограммы → обучение → экспорт. В основе — [microWakeWord](https://github.com/kahrendt/microWakeWord): стриминговая CNN-архитектура MixedNet; вход — мел-спектрограммы из `pymicro_features` (40 бинов, кадр 10 мс), выход — int8 TFLite для ESPHome.

Для «Алисы» (фразы «Алиса», «Алиса!», «Алиса?»):

- **Позитивы — ≈51 тыс. синтезированных клипов** в трёх движках: Piper (4 русских голоса), Silero v5.5 (5 голосов), Kokoro-RU (3 голоса). Разные голоса и интонации — чтобы модель не зависела от тембра.
- **Негативы — ≈26 тыс. синтезированных клипов** со словами и фразами, похожими по звучанию: «Лиса», «Алина», «Алло», «Александр», «Галина», «Погоди» и т. п., а также английские ложные срабатывания (Alice, Alyssa, Alexa, Lisa) — против срабатываний на ТВ и YouTube.
- **Публичный датасет негативов** [kahrendt/microwakeword](https://huggingface.co/datasets/kahrendt/microwakeword): речь, не-речь, застольные разговоры.
- **Аугментации**: SpecAugment (маски по времени и частоте) и вшивание коротких клипов в шумовой фон (SNR 0–12 дБ) — чтобы модель училась на «слово в комнате», а не на «слово + тишина».
- **Fine-tune на реальных записях** с микрофона ESP32-S3: 15 записей в обучении, 6 отложены для контроля.

**Проверка.** Точность на валидации — 99.7%. На реальных записях: 22/22 срабатываний (отложенные 6/6), на негативах вероятности ≤0.4 — ложных срабатываний нет.

## Как использовать (ESPHome)

1. Скопируйте из папки модели оба файла в папку конфигов ESPHome (рядом с YAML устройства).
   Держите их вместе и не переименовывайте по отдельности: манифест ссылается на tflite по относительному пути.
2. Добавьте в YAML устройства:

   ```yaml
   micro_wake_word:
     models:
       - model: <имя>.json
   ```

3. `Clean Build Files` → `Install` (OTA).

Требования: ESPHome ≥ 2024.2, микрофон 16 кГц.

## Тюнинг (в манифесте модели)

- `probability_cutoff` — ниже = чувствительнее (больше ложных), выше = строже.
- `sliding_window_size` — больше = стабильнее, но чуть позже реакция.

Правьте значения в `.json` и пересобирайте прошивку.
