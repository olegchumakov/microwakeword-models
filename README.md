# alisa-wakeword-models

Готовые модели распознавания (wake word) для ESPHome / microWakeWord.

## «Алиса» (русский)

Слово пробуждения: **«Алиса»**.

| | |
|---|---|
| Файлы | `alisa_mww.json` (манифест) + `alisa_mww.tflite` (модель) |
| Формат | microWakeWord v2 «micro» (streaming, int8) |
| Параметры | `probability_cutoff: 0.9`, `sliding_window_size: 10`, `feature_step_size: 10 ms`, `tensor_arena_size: 32000` |
| Требования | ESPHome ≥ 2024.2, микрофон 16 кГц |
| Обучение | синтетическая речь (piper / kokoro / silero, русские голоса) + реальные записи владельца, шумовые аугментации |
| Проверка | 22/22 реальных записей срабатывают устойчиво (скользящее среднее ≥ 0.94); ложных срабатываний на негативном наборе нет |

### Использование (ESPHome)

1. Скопируйте `alisa_mww.json` и `alisa_mww.tflite` в папку конфигов ESPHome (рядом с YAML устройства).
   Держите файлы вместе и не переименовывайте: манифест ссылается на модель по относительному пути.
2. Добавьте в YAML устройства:

   ```yaml
   micro_wake_word:
     models:
       - model: alisa_mww.json
   ```

3. `Clean Build Files` → `Install` (OTA). Модель вшивается в прошивку при сборке.

### Тюнинг

- `probability_cutoff` (сейчас `0.9`) — ниже = чувствительнее (больше ложных), выше = строже.
- `sliding_window_size` (сейчас `10`) — больше = стабильнее, но чуть позже реакция.

Правьте значения в `alisa_mww.json` и пересобирайте прошивку.
